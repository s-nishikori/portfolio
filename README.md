## 使用ツール

* [NEXT.js](https://nextjs.org/)
* [shadcn/ui](https://ui.shadcn.com/)

## Getting Started

1. 実行環境の構築: プロジェクトのルートディレクトリで、以下のコマンドを実行してDockerコンテナを起動する

```
docker compose up -d
```

2. 開発サーバーの起動

```bash
docker exec -it portfolio-app-1 bash
npm run dev
```

3. [http://localhost:3000](http://localhost:3000) にアクセス
